## Plan Mode

- Make the plan extremely concise. Sacrifice grammar for the sake of concision.
- At the end of each plan, give me a list of unresolved questions to answer, if any.

## Development

- Prefer simple solutions. Avoid premature abstractions.
- Keep changes focused on the current task.
- Only create or update documentation when explicitly requested.
- Add code comments only when the reasoning isn't obvious from the code itself.
- If an implementation becomes hacky or convoluted, flag it rather than silently adding complexity.
